## 🚀 Sobre o Projeto

Este projeto consiste na criação e constante modernização do meu portfólio pessoal. Ele foi projetado com foco em **experiência do usuário (UX)**, **estrutura HTML semântica**, **design 100% responsivo** e **interatividade em JavaScript**.

### ✨ Principais Recursos do Portfólio:
- **Galeria Interativa de Certificados:** Sistema de *Lightbox* personalizado que amplia as imagens em tela cheia com plano de fundo escurecido, fecho por tecla `Esc` ou clique fora/no botão "X".
- **Design Adaptativo:** Layout fluido ajustado para smartphones, tablets e desktops.
- **Centralização de Projetos:** Vitrine organizada dos trabalhos freelances, comerciais e projetos práticos.
